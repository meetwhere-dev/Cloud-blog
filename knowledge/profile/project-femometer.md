# Femometer 外贸独立站

**前端开发 · 2022.08–至今**

为海外用户提供商品展示与购买流程，支持 Stripe、PayPal、Apple Pay 和 Google Pay 等支付方式。

- 使用 Nuxt.js 与 SSR，接入多平台埋点，支持多语言与 SEO 优化。
- AI 客服以 Node.js、Mastra 为主要框架，通过知识图谱检索相关资料，使用工作流处理退换货等售后流程。
- 支持在对话中处理售前、售后问题，连接网站商品和业务服务。
