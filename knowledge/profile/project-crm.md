# 海外品牌达人合作管理系统

## 项目背景与时间

面向海外品牌的达人合作管理场景，将原本分散在表格、邮件和不同业务工具中的合作信息集中管理，让团队与达人在统一流程中协作。

时间：2026 年 3 月至今。

## 本人职责

负责全链路开发，包括前端、后端及飞书审批集成。系统包含中文管理后台与英文达人自助端，两个入口共用一套业务数据。

## 技术方案与业务范围

使用 React、TypeScript、Node.js 和 PostgreSQL 搭建系统，并对接原有业务工具。

管理流程覆盖达人建档、筛选与批量操作、合同签署与审批、寄样换货、物流同步、内容审核、自动催稿及季度结算。达人可通过自助端提交资料、查看进度。

## 关键问题与解决方法

### 同一达人存在多次合作

按每次合作分别管理合同、寄样、内容与结算，避免不同合作之间的资料混淆，便于持续跟进。

### 合作周期长且跨多个系统

将合同、物流、内容和结算等环节串联，并集成飞书审批及既有业务工具，支持在统一流程中处理和跟踪合作。

### 批量操作与异常处理

加入权限控制、批量处理与失败重试，减少重复操作，方便跟进异常。

## 已实现成果

已实现达人建档、合同签署、寄样换货、内容审核和结算管理等主要功能；将分散信息集中管理，并提供达人自助提交资料、查看进度的入口。
