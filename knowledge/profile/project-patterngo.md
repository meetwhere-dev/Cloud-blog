# PatternGo 在线服装打版系统

**Web 前端 · 2020.04–2022.07**

帮助服装设计师与版师更高效地产出版型。项目采用 Vue CLI、Vuex、SCSS，使用 Fabric.js、Lodash、Axios 等工具。

- 开发口袋、拉链、省褶、活褶等服装物件及系统界面，抽离并维护工具库。
- 与服装设计师沟通需求、交互效果及实现成本，以面向对象方式抽象父类并扩展具体物件。
- 独立设计系统一半以上的物件，参与问题排查与 UI 组件库建设。
