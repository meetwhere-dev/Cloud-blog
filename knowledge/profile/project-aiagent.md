# 官网 AI 客服 Agent

## 项目背景与时间

随着销售增长，客服咨询压力增加。项目旨在通过 AI 客服承接商品咨询和常见问题，并连接业务查询与人工服务，减轻客服负担。

时间：2026 年 3 月至今。

## 本人职责

担任全栈开发，主导官网 AI 客服从 0 到 1 落地。工作覆盖前端交互、后端会话与业务流程、大模型接入，以及飞书、Zendesk 人工客服转接。

## 技术方案

- 前端使用 Vue 与 UnoCSS，通过 SSE 接收回答和商品、订单卡片。
- 后端使用 TypeScript、Node.js，通过 Mastra 接入大模型，结合知识库和业务接口，提供商品咨询、常见问题解答、订单与物流查询。
- 使用 Redis 管理会话，MySQL 保存聊天与业务记录。
- 对接飞书、Zendesk，将需要人工处理的问题转入人工客服流程。

## 关键问题与解决方法

### 限制缺乏业务依据的回答

价格、订单和发货信息从真实业务接口获取，回答前校验数据与用户权限。通过这些措施降低错误回答和越权查询风险。

### 保持多轮沟通连贯

记录用户已提供的信息与当前处理进度，支持补充、修改及暂停后恢复，减少重复询问。

### 避免误提与重复工单

提交前展示问题摘要，经用户确认后再提交；记录提交状态，并处理重复请求和接口异常。

### 适配不同地区

按商品、销售地区与收货国家匹配业务数据，结合缓存和定时刷新改善查询效率。

## 已实现成果

已实现从自助咨询、业务查询到人工客服转接的完整后端流程。常见问题可以直接返回标准答案，无需调用大模型。

已建立自动化测试与场景评测，并记录请求耗时、用户评价等数据，为后续评估和改进提供基础。
